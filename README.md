# TILWithClaude

Daily TIL: learning networking, Linux, cloud and C++/C# with Claude as a study partner, verified by solving problems myself

## 목표
- 네트워크관리사 2급 → CCNA → RHCSA → Azure(AZ-104) 순서로 자격증 준비
- C++ / C# / CS 기초를 AI와 함께 공부하고 포트폴리오로 연결

## 학습 방식
1. 하루 분량을 정하고 Claude에게 설명과 문제를 받는다
2. **답을 직접 써서 제출**하고 채점받는다 (AI 답을 그대로 외우지 않는다)
3. 틀린 문제는 "틀린 것"에 기록하고 다음 날, 일주일 뒤에 다시 푼다
4. AI가 한 말은 문제 풀이와 실습으로 한 번 더 확인한다
