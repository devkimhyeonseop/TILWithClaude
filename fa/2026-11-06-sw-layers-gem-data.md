# 2026-11-06 FA 심화 2: 장비 소프트웨어 계층·GEM 데이터 구분

## 배운 것
- 계층: 호스트(MES) → 장비 컨트롤러 → 모듈 컨트롤러 → 장치 제어(PLC·모션·I/O) → 센서·액추에이터
- 호스트↔장비는 SECS/GEM(HSMS), 장비 내부는 제조사마다 다름
- 장비가 호스트에 올리는 것: 이벤트(정상적인 일의 알림), 알람(이상), 데이터(측정값)
- 기판 위치 추적·이동 순서는 장비 컨트롤러, 로봇을 실제 구동하는 건 모듈 컨트롤러

## 틀린 것
- 센서 이상 시 호스트에 보내는 것을 "반출"로 답함 (정답: 알람)
- 이벤트·알람을 "알림·경고"로 풀어 말함 (개념은 맞음, 정식 용어로 말하기)

## 다시 볼 것
