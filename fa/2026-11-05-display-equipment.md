# 2026-11-05 FA 심화 1: 디스플레이 장비 큰그림

## 배운 것
- 공정 흐름: 기판 투입 → 로드락 → 반송 챔버 → 증착 챔버 → 반송 → 로드락 → 반출
- 로드락은 대기와 진공 사이의 완충 공간 (증착 챔버의 진공을 깨지 않고 기판을 넣고 뺌)
- 반송 챔버의 로봇이 챔버 사이로 기판을 옮김, 증착 챔버는 진공에서 박막을 입힘
- OLED에서 유기층은 열증착, 전극·투명전극은 스퍼터링 (둘은 다른 방식)
- 장비 소프트웨어 5가지: 레시피 실행, 반송 제어, 상태 관리, 데이터 수집·알람, 호스트 통신(SECS/GEM, HSMS)

## 틀린 것
- "기판 분석"을 장비 소프트웨어의 일로 답함 (검사 장비의 일)
- 위치 추적과 로봇 이동 지시를 "호스트 통신"으로 답함 (정답: 반송 제어)

## 다시 볼 것
- 반송 제어는 장비 안의 일, 호스트 통신은 장비 밖(MES)과의 일
- FA 심화 2에서 장비 소프트웨어 구조를 더 깊게
