# 2026-11-08 정보보호개론: 보안 기초·암호·방화벽

## 배운 것
- 보안 3요소: 기밀성(허락된 사람만), 무결성(내용 불변), 가용성(필요할 때 사용)
- 대칭키(같은 키, 빠름, AES·DES) / 비대칭키(공개키·개인키 한 쌍, 느림, RSA)
- 해시: 되돌릴 수 없는 요약값, 무결성 확인 (SHA-256, MD5)
- 전자서명: 개인키로 서명, 공개키로 검증 (위조·부인 방지)
- 방화벽: 허용 규칙에 맞는 트래픽만 통과, 규칙은 위에서 아래로 먼저 맞는 것 적용
- IDS(탐지만, Detection) / IPS(탐지 + 차단, Prevention)
- DMZ: 외부에 공개하는 서버(웹·메일)를 두는 내부망과 인터넷 사이의 완충 구역 (군사 용어 비무장지대에서 따온 이름)

## 틀린 것
- "탐지만 하는 장비 / 탐지+차단 장비"를 "방화벽"으로 답함 (정답: IDS / IPS)
- "외부 공개 서버 구역"을 "DNS"로 답함 (정답: DMZ)
- 두 번째도 같은 답이 나와서 이름의 뜻(Prevention, 비무장지대)으로 외운 뒤 맞힘

## 다시 볼 것
- IDS/IPS, DMZ는 내일과 일주일 뒤에 한 번 더
- 방화벽과 IPS의 차이 (규칙 기반 통과 vs 침입 탐지·차단)

## AI에게 확인한 것
- 확인 문제 6개 + 재확인으로 점검함
- DMZ 이름의 유래는 질문으로 확인함 (군사 용어를 네트워크에 빌려 씀)
