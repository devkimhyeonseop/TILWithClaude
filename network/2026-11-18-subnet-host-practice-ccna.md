# 2026-11-18 주간 1일차: 서브넷(호스트 기준) 연습, CCNA 오답(플로팅 스태틱 3회차), 동적 라우팅·AD 기초

## 배운 것
**서브넷 — 서브넷 개수 기준 vs 호스트 개수 기준 구분 연습**
- 서브넷 N개 필요 → 2ⁿ≥N인 n부터(마스크 = 기본+n)
- 호스트 N대 필요 → 2ʰ−2≥N인 h부터(C클래스는 8−h, B클래스는 16−h를 뺀 게 빌린 칸)
- C클래스는 호스트 칸이 최대 8개라 254개가 한계. 500대처럼 넘어가면 C클래스 하나로는 불가능, B클래스로 가야 함
- 필요 호스트 수가 기본 마스크로 충분하면 쪼갤 필요 없음(예: C클래스에서 200대 → 그대로 /24)
- B클래스는 호스트 칸이 16개라서 "8에서 빼기"가 아니라 "16에서 빼기"로 계산해야 함(틀렸던 부분)

**동적 라우팅과 AD (기초부터)**
- 정적 라우팅: 내가 직접 `ip route`로 길을 적어줌. 끊겨도 라우터가 스스로 못 고침
- 동적 라우팅: 라우터들이 서로 정보를 주고받아(OSPF, EIGRP, RIP, BGP 등) 자동으로 길을 찾음. 끊기면 자동 우회
- AD(관리 거리): 여러 경로 정보 중 무엇을 믿을지 정하는 점수, 숫자가 낮을수록 믿음 (직접연결 0, 정적 1, EIGRP 90, OSPF 110, RIP 120)
- 정적 경로 기본 AD는 1이라 동적보다 항상 이김. "동적이 있으면 동적 우선, 없으면 정적"을 원하면 정적 AD를 동적보다 크게(`ip route ... [AD숫자]`) 줘서 플로팅 스태틱을 만듦

**CCNA 덤프 10문제 중 7개 오답**
- 반복 오답: d2-22(플로팅 스태틱, 세 번째 틀림), d2-52(사설 IP 172.16~172.31 범위), d2-56(MAC 학습은 폐기 아니라 플러딩)
- 신규 오답: d2-242(콜랩스드 코어=작고 비용 줄이는 조직용), d2-243(dynamic auto=수동적으로 트렁크 수락), d2-294(Hotspot=캡티브 포털 AP 기능), d2-519(SNMPv2 신규 기능=GetBulk+Inform)

## 틀린 것
- 서브넷: B클래스 호스트 문제에서 "8에서 빼기"를 그대로 써서 틀림(16에서 빼야 함)
- 플로팅 스태틱(d2-22)이 11/14·16·18 세 번 연속 틀림 — AD 숫자를 더 크게/작게 주는 방향을 헷갈림
- d2-52, d2-56도 이전에 틀렸던 것과 동일한 이유로 또 틀림

## 다시 볼 것
- 동적 라우팅을 사실 공부 안 하고 CCNA 문제만 풀고 있었다는 걸 확인함 → AD·플로팅 스태틱은 개념부터 다시 설명받아 이해함
- B클래스 호스트 계산에서 16−h 공식 적용 연습
- d2-22, d2-52, d2-56은 다음에도 우선 복습
