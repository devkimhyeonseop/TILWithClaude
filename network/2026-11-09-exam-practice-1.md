# 2026-11-09 필기 기출 유형 풀이 (1/3)

## 배운 것
- 메일 보내기는 SMTP(25), 받기는 POP3(110)·IMAP(143)
- DNS: A(이름→IP), PTR(IP→이름)
- 리눅스: chmod는 권한(mode), chown은 소유자(owner)
- umask는 "빼는 값": 파일 666−022=644(rw-r--r--), 디렉터리 777−022=755
- DHCP 67/68, FTP 제어 21·데이터 20, 스위치 플러딩, IDS(탐지)·IPS(탐지+차단), DMZ는 맞힘

## 틀린 것
- 메일을 보내는 프로토콜을 POP으로 답함 (정답: SMTP 25)
- IP→이름 레코드를 A로 답함 (정답: PTR)
- 권한 변경 명령어를 chown으로 답함 (정답: chmod)
- umask 022의 새 파일 권한을 022 자체를 권한처럼 읽어 틀림 (정답: 666−022=644)
- 10문제 중 6개 맞힘, 틀린 4개는 재확인에서 모두 맞힘

## 다시 볼 것
- SMTP=Send, chmod=mode, chown=owner, PTR=Pointer(역방향)
- umask는 빼는 값 (파일 666, 디렉터리 777에서 뺌)
- 기출 풀이 2/3, 3/3에서 오늘 틀린 유형이 다시 나오는지 확인
