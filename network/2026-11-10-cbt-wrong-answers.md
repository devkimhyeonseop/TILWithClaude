# 2026-11-10 필기 CBT 기출 풀이: 오답 23문제 정리

## 배운 것
- 서브넷: 호스트 수 = 2^(0의 개수) − 2 (192→62, 224→30, 240→14, 248→6). 마스크 224 = 128+64+32 = 11100000
- 클래스: A 1~126, B 128~191, C 192~223
- IP 체크섬은 헤더만 검사, 포트 번호는 TCP/UDP(4계층) 헤더
- 프로토콜: IGMP(멀티캐스트 그룹), SIP(세션 시작·관리, 5060), SSH 22 / Telnet 23
- DNS: SOA(영역 권한), A, PTR, MX. BIND zone 파일 위치는 directory '/var/named'
- TDM은 고정 슬롯이라 빈 슬롯도 낭비, 세션 계층에는 에러 제어가 없음(데이터링크)
- netstat: -a 전체, -n 숫자, -t TCP, -u UDP, -r 라우팅, 리눅스 -p(PID·프로그램), 윈도우 -b(실행 파일)
- cron: 분 시 일 월 요일 (요일 0=일, 1=월) → 매주 월요일 10시는 `0 10 * * 1`
- Distance Vector = RIP·IGRP, OSPF = Link State, RAID-5 = 회전(분산) 패리티, 논리적 분리 = VLAN

## 틀린 것

- 서브넷 호스트 수를 1의 개수로 계산해서 틀림 → 0의 개수로 세기로 바로잡음
- 그림 문제 4개(7, 23, 26, 48)는 지문 이미지를 AI가 보지 못해 정답 기준으로 정리
