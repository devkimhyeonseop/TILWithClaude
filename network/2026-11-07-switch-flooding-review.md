# 2026-11-07 복습: 스위치 플러딩·기본 게이트웨이·FA 용어

## 배운 것
- 스위치: 모르는 MAC은 모든 포트로 뿌림(플러딩) → 출발지 MAC 학습 → 이후 해당 포트로만 전달 (2계층)
- 라우터: 맞는 경로가 없으면 기본 게이트웨이로 보냄 (3계층)
- 이벤트(정상 알림)·알람(이상)·데이터(측정값), DNS A(이름→IP)·PTR(IP→이름, 끝자리만 입력)
- 약점 4줄(fstab, df, DHCP 67/68, PTR) 모두 맞힘

## 틀린 것
- 스위치가 모르는 MAC을 받았을 때를 "기본 게이트웨이로 보냄"이라고 답함 (라우터 동작과 섞임)
- 첫 답에서 이벤트·알람·데이터 중 일부만, PTR은 빼고 답함 (재확인에서 맞힘)
