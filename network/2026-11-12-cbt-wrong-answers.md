# 2026-11-12 필기 CBT 3세트 풀이: 오답 43문제

## 배운 것
- ICMPv6의 이웃 요청·광고(NS/NA)가 IPv4의 ARP 역할을 함. Echo는 ping, Redirect는 더 나은 경로 안내
- IP는 L3, 비연결형·비신뢰성. 신뢰성·오류제어·슬라이딩 윈도우 흐름제어는 TCP 기능
- TCP 헤더: 포트 16, Seq 32, Ack 32, Flags 9, Window 16, Checksum 16비트
- IPv6 요약 복원은 블록이 8개가 되도록 앞의 0을 복원하고 ::를 0000 블록으로 채움. IPv6 헤더에는 체크섬이 없음
- 교환 방식: 경로 설정 후 전송하고 일정 시간 전송이 없으면 해제하는 것은 가상회선. 위상 왜곡은 주파수마다 도착 시간이 다른 손실
- 메시 네트워크는 분산형·자동 구성이라 중앙 제어 없이도 구성 가능
- ARQ는 Stop-and-Wait·Go-Back-N·Selective Repeat 3종. FEC는 재전송 없이 정정해서 ARQ가 아님
- SIP는 통화·화상 세션을 시작·종료하는 신호 프로토콜. HEVC는 영상 압축, MIME은 메일 형식
- 서버리스는 서버·OS 패치를 제공자가 관리. 클라우드는 다중 임차(multi-tenant)
- L2=MAC, L3=IP, L4=포트(L4 스위치는 전송 계층), L7=URL·내용
- VLAN 태그 전달은 Tagged 포트(802.1Q). PoE는 UTP로 데이터와 전원을 함께 공급. RAID-5는 회전 패리티
- NAT는 L3 주소 변환. DNSSEC은 무결성·출처 인증이지 암호화가 아님. DHCP는 UDP 67/68, DORA
