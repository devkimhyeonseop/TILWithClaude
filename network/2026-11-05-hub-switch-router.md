# 2026-11-05 허브·스위치·라우터 / 주소 변환(NAT)

## 배운 것
- 허브(1계층): 받은 신호를 모든 포트로 뿌림. 리피터(1계층): 신호 증폭
- 스위치(2계층): MAC 주소 테이블을 보고 필요한 포트로만 전달
- 라우터(3계층): IP와 라우팅 테이블로 경로 결정, 포트마다 브로드캐스트 도메인 분리
- NAT 실습(윈도우 서버 RRAS): 공용 인터페이스에서 주소 풀 등록, 서비스 및 포트에서 포트 포워딩
  - 칸 순서: 들어오는 포트 → 개인 주소 → 나가는 포트 (서비스 설명은 비우면 확인이 안 눌림)

## 틀린 것
- 허브와 스위치를 서로 바꿔 답함 (허브는 모두에게 뿌림, 스위치는 MAC을 보고 보냄)
- 신호 증폭 장비를 라우터로 답함 (정답: 리피터)

## 다시 볼 것
- 1계층: 허브·리피터 / 2계층: 스위치 / 3계층: 라우터
- 들어오는 포트와 나가는 포트는 같아도 되고 달라도 됨 (문제 값대로)

## AI에게 확인한 것
- AI가 준 장비 비유(허브=아무에게나 뿌림, 스위치=주소 보고 전달)를 문제 5개와 확인 3개로 직접 풀어 점검함
- 포트 포워딩 칸 이름은 에뮬레이터 화면에서 직접 입력해 확인함
