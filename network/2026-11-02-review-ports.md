# 2026-11-02 복습: 포트·TCP 3단계·PTR·IIS 경로

## 배운 것
- DHCP는 서버 UDP **67**, 클라이언트 UDP **68** (서버가 먼저, 클라이언트가 나중)
- FTP는 제어 **21**, 데이터 **20**
- DHCP의 DORA(Discover → Offer → Request → Ack)와 TCP 연결 설정(**SYN → SYN+ACK → ACK**)은 서로 다른 과정이다
- 고정 IP 설정 값은 IP 주소, 서브넷 마스크, 기본 게이트웨이, **DNS 서버**다 (MAC 주소는 설정 값이 아님)
- PTR 레코드를 만들 때 호스트 IP 칸에는 **마지막 숫자만** 쓴다 (FQDN 줄이 `10.10.168.192.in-addr.arpa` 형태로 나오는지 확인)
- IIS에서 웹 문서 폴더는 **실제(물리적) 경로**, 기본 문서는 접속 시 처음 열리는 파일 이름이다

## 틀린 것
- DHCP 포트를 22·23으로, FTP 포트를 57·58로 답함 (세 번째 반복 오답) → 67/68, 21/20
- TCP 3단계를 "탐색 발견 응답"으로 답함 → DHCP의 DORA와 혼동했다. SYN → SYN+ACK → ACK
- 고정 IP 값에 DNS 서버 대신 MAC 주소를 씀
- PTR 칸과 IIS 경로 항목을 기억하지 못함

## 다시 볼 것
- DHCP 67/68, FTP 21/20은 내일 아침 첫 문제로 다시 확인
- DORA와 TCP 3-way는 이름을 따로 붙여 구분하기 (IP를 받는 과정 vs 연결하는 과정)
