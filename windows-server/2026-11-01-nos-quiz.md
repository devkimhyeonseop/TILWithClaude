# 2026-11-01 윈도우 서버 필기(NOS) 첫 문제 풀이 + 포트 복습

## 배운 것
- 도메인은 서버(Active Directory, AD DS)에서 계정·정책을 중앙 관리하고, 워크그룹은 PC마다 따로 관리한다
- 서버 역할: DNS(이름→IP), DHCP(IP 자동), IIS(웹), 파일·프린트·원격 데스크톱(3389)
- NTFS는 권한·암호화·압축 지원, 공유 권한과 NTFS 권한이 다르면 더 제한적인 쪽이 적용
- 기본 계정 Administrator, Guest(기본 비활성), 로그는 이벤트 뷰어, 서비스는 services.msc, 조회는 nslookup

## 틀린 것
- AD DS를 "계정 서비스"로 답함 (방향은 맞음)
- 이름→IP 서버 역할을 "도메인"으로 답함 → DNS
- 시스템 로그 도구를 작업 관리자로 답함 → 이벤트 뷰어
- 공유·NTFS 권한 충돌을 "NTFS가 적용"으로 답함 → 더 제한적인 쪽
- DNS 조회 명령어를 모름 → nslookup
- 복습: DHCP 67/68, FTP 21(제어)/20(데이터), TCP 3단계(SYN → SYN+ACK → ACK), 고정 IP 값 4가지를 다시 틀림

## 다시 볼 것
- DHCP 67/68, FTP 21/20 (내일 아침 첫 문제)
- 실기 윈도우 서버 2/3: DNS 영역·레코드, IIS 웹사이트 (PC 실습은 비번에)
