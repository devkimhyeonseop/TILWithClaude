# 2026-11-04 윈도우 서버 실기 3/3: 사용자·그룹, 폴더 공유, 폴더 권한

## 배운 것
- 관리도구 → **로컬 사용자 및 그룹**: 사용자 폴더 우클릭 → 새 사용자(이름, 암호, 암호 옵션) → 만들기
- 그룹 만들기: 그룹 우클릭 → 새 그룹 → 이름 → 멤버 추가, 기존 사용자는 속성 → 소속 그룹에서 추가
- 관리도구 → **공유 폴더**: 공유 우클릭 → 새 공유 → 폴더 경로·공유 이름 → 권한(읽기 / 변경 / 모든 권한)
- 컴퓨터 → **폴더 권한**: 폴더 속성 → 보안 탭 → 사용자·그룹 추가 → 허용/거부 (거부가 허용보다 우선)
- 공유 권한과 NTFS 권한이 다르면 더 제한적인 쪽이 적용된다
