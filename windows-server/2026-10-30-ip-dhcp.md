# 2026-10-30 윈도우 서버 실기: 고정 IP·DHCP

## 배운 것
- 고정 IP: 네트워크 속성 → Internet Protocol Version 4 (TCP/IPv4) → 속성 → "다음 IP 주소 사용"
- 입력 값 4가지: IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버
- DHCP 범위: 관리도구 → DHCP → IPv4 우클릭 → 새 범위 → 시작/끝 IP → 제외 범위 → 임대 기간 → 라우터·DNS 옵션 → 활성화
- 클라이언트 `ipconfig /release`(반납), `ipconfig /renew`(새로 받기), 확인 `ipconfig /all`

## 틀린 것
- IPv6 창을 열었음 → 고정 IP는 **IPv4** 속성에서
- 입력 값을 "ip, 게이트웨이, 도메인 이름"으로 답함 → 서브넷 마스크와 DNS 서버를 빠뜨림
- 특정 IP를 나눠 주지 않는 설정을 모름 → **제외 범위**
- `ipconfig`만 씀 → `/release`, `/renew`
