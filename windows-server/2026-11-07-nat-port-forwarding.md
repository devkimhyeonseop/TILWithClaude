# 2026-11-07 실기: 라우터(NAT) 설정 2/3

## 배운 것
- 공용 인터페이스 = 외부(인터넷) 쪽, 개인 인터페이스 = 내부(LAN) 쪽
- 주소 풀: 공인 IP 범위(시작·끝·마스크) 등록
- 포트 포워딩: 들어오는 포트(바깥에서 두드리는 번호) → 개인 주소(내부 서버 IP) → 나가는 포트(안쪽에 넘기는 번호)
  - 외부 8080 → 내부 80이면 들어오는 8080, 나가는 80 (같아도 되고 달라도 됨)
- 서비스 설명 칸이 비어 있으면 확인이 안 눌림

## 틀린 것
- 공용 인터페이스를 "내부"라고 답함 (외부가 정답)
- 외부 8080 → 내부 80에서 들어오는 포트를 80으로 답함 (방향 반대, 정답 8080)
- 두 번째 확인(2121 → 21)에서는 모두 맞힘

## 다시 볼 것
- 공용 = 공공(인터넷), 개인 = 우리 집(LAN)
- 포트 방향: 들어오는 = 바깥사람이 누르는 번호
