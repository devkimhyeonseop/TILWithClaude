# 2026-11-11 실기 모의(샘플 화면): IIS·DNS·FTP·계정·서비스·ARP

## 배운 것
- **IIS 접속 허용**: 사이트(ICQA) 선택 → IP 주소 및 도메인 제한 → 허용 항목 추가 → IP 주소 범위 `211.111.100.0`, 마스크 `255.255.255.0`(/24). 이어서 기능 설정 편집에서 지정되지 않은 클라이언트를 **거부**로 바꿔야 해당 범위만 허용됨
- **DNS 영역**: icqa.or.kr 정방향 영역에 www(A) `192.168.100.100`, ftp(CNAME) `www.icqa.or.kr`. SOA 속성의 주 서버 `ns.icqa.or.kr.`, 책임자 `admin.icqa.or.kr.`(@ 대신 점). 일련 번호는 자동 증가
- **FTP 사이트 고급 설정**: 이름·바인딩(IP:21)·실제 경로·데이터 채널 시간 제한 45초·소켓 풀링 사용 안 함 = True·최대 연결 수 20을 한 화면에서 확인
- **로컬 보안 정책**: "계정: Administrator 계정 이름 바꾸기"를 icqaadmin으로, "계정: Guest 계정 상태"를 사용 안 함으로
- **서비스**: World Wide Web Publishing Service를 중지하고 시작 유형을 사용 안 함으로. 시작 유형만 바꾸면 실행 중인 서비스가 멈추지 않으므로 중지 버튼도 눌러야 함
- **ARP 캐시 삭제**: `arp -d *` (조회는 `arp -a`). 명령어와 옵션은 띄어쓰기로 구분
- 서버 운영 방법: 공유 호스팅(일부 공간 임대) / 전용 호스팅(물리 서버 단독) / 클라우드 호스팅(가상 서버, 쓴 만큼 과금)

## 틀린 것
- ARP 캐시 삭제 명령을 `ipconfig`로 적음
- DNS SOA 주 서버·책임자를 기본값(ICQAServer., hostmaster.) 그대로 두었다가 수정함
- IIS에서 허용 항목만 넣고 기본값 거부를 빠뜨릴 뻔함
- 확인 버튼을 누르기 전 상태에서 "이렇게 하면 되나?"를 물음. 설정 후 저장·확인 버튼과 목록 반영 확인을 습관으로 만들기
