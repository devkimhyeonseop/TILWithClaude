# 2026-11-24 주간 1일차: CCNA 개념 커리큘럼 시작(VLAN 기초), CCNA 덤프 10문제(8개 오답)

## 배운 것
- 오픽 데일리 3문제 완료
- **CCNA 개념 커리큘럼 Day 1 시작**: 덤프·복습과 별도로 2026-12-23 CCNA 시험까지 30일 개념 학습 계획을 세움(주차별: 네트워크 액세스 → IP 커넥티비티 → IP 서비스 → 보안/자동화)
  - VLAN 기초: VLAN 태그(802.1Q)는 스위치 간 trunk 구간에서만 붙고, access 포트에 연결된 일반 PC는 VLAN을 몰라서 태그 없는 평범한 프레임만 주고받음(스위치가 포트 소속만 보고 내부적으로 구분). 서로 다른 VLAN끼리는 기본적으로 통신 불가(분리된 네트워크로 동작)
  - 확인 문제 3개 중 2개는 바로 맞혔고(trunk 포트 선택, VLAN 간 통신 불가), access 포트에서 태그가 "붙는다"고 착각한 1개는 개념 설명 듣고 이해함

**CCNA 덤프 10문제 중 8개 오답(d2-286, d2-274만 정답), 개념별 정리**
- TCP vs UDP: TCP=순서 보장·재전송(신뢰성), UDP=비연결·저지연·고처리량(d2-291)
- REST 헤더: Content-Type=보내는 본문 형식, Accept=받고 싶은 응답 형식 — 요청 본문이 JSON이면 Content-Type을 써야 함(d2-285)
- EtherChannel 장애 대비: `port-channel min-links 1`로 설정하면 멤버 링크 하나만 살아있어도 채널 유지(d2-245)
- 자동화·데이터 모델: YANG 같은 표준 데이터 모델을 쓰면 벤더 종속 없이 같은 방식으로 관리 가능(d2-275)
- WLC WPA2 설정: PSK 방식은 Auth Key Mgmt=PSK, 키가 문자열이면 PSK Format=ASCII, Layer2 Security는 WPA2 Policy+AES 체크(d2-314)
- 서브넷 불일치 트러블슈팅: 잘못된 서브넷 마스크(/28)를 실제 대역(/29, 255.255.255.248)에 맞게 고치고 그 범위 안의 IP를 써야 함(d2-287)
- SDN 보안 장점: 컨트롤러 한 곳에서 정책을 정해 모든 장비에 일관 적용 — 11/22에도 틀렸던 반복 개념(d2-288)
- SSID 보안 강화: Broadcast SSID "체크 해제"가 정답인데 오늘도 "체크"로 답해 또 틀림 — 11/23 복습에선 맞혔다가 재발(d2-277)
