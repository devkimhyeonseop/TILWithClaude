## 배운 것
- 오픽 데일리 3문제 완료
- **CCNA 개념 커리큘럼 Day 3: VLAN 호핑 공격과 방어** — 이중 태깅 공격(공격자가 프레임에 태그 2겹을 씌워 보내면, 스위치가 바깥쪽 태그를 네이티브 VLAN으로 착각해 벗기고 안쪽 태그로 원래 접근 못 할 VLAN에 넘어가버림)의 원리와, 네이티브 VLAN을 일반 사용자가 안 쓰는 전용 VLAN으로 분리하는 방어법을 확인 문제로 점검
  - 확인 문제 3개 중 2개(네이티브 VLAN 공유 시 방어 안 됨, 포트 보안으로는 막을 수 없음)는 바로 맞혔고, "공격자 포트 VLAN이 네이티브 VLAN과 같아야 공격이 성립한다"는 조건만 교정받음

**CCNA 덤프 10문제 중 9개 오답(d2-294만 정답), 개념별 정리**
- HSRP vs VRRP: HSRP는 Cisco 독자, 개방형 표준은 VRRP(d2-284)
- WLC LAG 모드: WLC는 LACP/PAgP 협상을 지원 안 해서 스위치 쪽은 `mode on`으로 고정(d2-244)
- PKI 구성요소: CA(인증서 발급) + CRL(폐기 목록)(d2-272)
- Digest 인증: 챌린지-응답 메커니즘으로 비밀번호 원문을 안 보냄(d2-317)
- 컨트롤 플레인: 다른 라우터와 토폴로지 정보 교환(데이터 플레인=전달, 관리 플레인=CLI 접근)(d2-367)

**복습 퀴즈 5문제 중 2개 정답(SSID 체크 해제, PortFast 방향은 근접)**
- southbound API 방향: 컨트롤러↔장비(하드웨어) — **다섯 번째 반복 오답**, 오늘 "남(south)=땅(아래)=장비, 북(north)=하늘(위)=애플리케이션" 암기법으로 재설명
- FHRP 이점 두 번째: 여러 라우터를 가상 게이트웨이 하나로 통합 — 자동 장애 조치만 기억하고 이것 놓침
- PortFast 이유: "빠른 연결"까지는 맞는 방향이었으나, 정확히는 즉시 forwarding 전환 + TCN 미발생 두 가지
- GETVPN은 맞혔으나 DMVPN을 놓침

- 복습: southbound 방향(5회째), FHRP 이점 2번째, PortFast 정확한 두 이유, DMVPN

## 다시 볼 것
- southbound/northbound은 다섯 번 연속 반복 오답 — 오늘 새 암기법(남=땅=장비, 북=하늘=앱)이 통하는지 내일 재확인
- FHRP 이점 2가지 중 "가상 게이트웨이 통합"을 계속 놓침 — 자동 장애 조치만 기억하고 있음
- PortFast는 방향은 잡혔으니 정확한 두 가지 표현으로 다시 확인
