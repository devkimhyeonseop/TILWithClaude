# 2026-11-20 야간 1일차: 오픽·CCNA 덤프 10문제(9개 오답) 개념 정리

**CCNA 덤프 10문제 중 9개 오답(d2-279만 정답), 개념별 정리**
- 정적 경로 방향: `ip route <목적지> <마스크> <다음 홉>`에서 다음 홉은 반드시 상대 라우터 주소여야 함. 자기 인터페이스 주소를 넣으면 루프 발생(d2-11, 반복 오답)
- 경로 요약(summarization): 10.1.40.0~10.1.41.255 전체 범위를 담는 가장 작은 블록은 10.1.40.0/23 (반복 오답, 요약=작은 망들을 다 담는 더 큰 박스)
- FHRP 종류: FHRP는 우산 용어, HSRP=Cisco 독자, VRRP=업계 표준, GLBP=Cisco 독자+부하분산. "독자(proprietary)"라고 하면 HSRP/GLBP만 해당(d2-109)
- 트렁크 협상: `dynamic desirable`=먼저 적극적으로 트렁크 요청, `dynamic auto`=상대 제안을 수동적으로 수락, `mode trunk`=협상 없이 고정(d2-115)
- VLAN 호핑 방어: 이중 태깅 공격은 네이티브 VLAN을 악용 → 일반 사용자 포트를 네이티브 VLAN과 분리해서 배정해야 함(d2-119, 반복 오답)
- SDN 보안 장점: 컨트롤러 한 곳에서 정책을 정의해 모든 장비에 일관 적용(전통 방식은 장비별 설정이라 오류 여지 큼)(d2-288)
- Southbound/Northbound API: Southbound=컨트롤러↔장비(하드웨어), Northbound=컨트롤러↔애플리케이션(d2-296)
- Syslog 심각도 레벨: 0(emergencies)~7(debugging) 총 8단계, 메시지의 심각도를 나타냄. 기본 전송 레벨은 6(informational)까지(d2-310)
- 다중 서브넷 생성(10.70.128.0/19에서 호스트 24개/472개용 두 서브넷): 아직 미해결, 서브넷팅 집중 시간에 이어서 풀기로 함(d2-240)

## 틀린 것
- d2-11: 정적 경로의 다음 홉에 자기 라우터 주소를 넣음 (3번째 이상 반복)
- d2-15: 요약 네트워크 범위를 좁게 잡음 (반복 오답)
- d2-109: FHRP 우산 용어와 HSRP/VRRP/GLBP 구분을 헷갈림
- d2-115: 트렁크 협상 모드(desirable vs auto vs trunk)를 혼동
- d2-119: VLAN 호핑 방어책을 포트 보안(MAC 제한)과 혼동 (반복 오답)
- d2-288, d2-296: SDN 컨트롤러의 보안 장점과 southbound/northbound API 방향을 혼동
- d2-310: syslog 레벨 개수·기본 전송 레벨을 잘못 앎
- d2-240: 여러 서브넷을 동시에 만드는 계산을 아직 풀지 못함
