**CCNA 덤프 10문제 중 9개 오답(d2-432만 정답), 개념별 정리**
- Syslog 레벨의 목적: 장비마다 어느 심각도 이상을 보낼지 기준을 정하는 것(`logging trap`), 메시지 출처 식별이 아님(d2-247)
- 벤더가 다른 스위치 간 트렁크: DTP 협상 끄고 `mode trunk`로 고정 + 표준 캡슐화 `dot1q` 사용(d2-276)
- 잘못된 서브넷 마스크 고치기: 호스트 PC의 IP·마스크 자체를 실제 서브넷 범위에 맞게 고쳐야 함, 게이트웨이·DNS만 바꾸는 건 근본 원인 해결 아님(d2-287)
- FHRP의 이점: 여러 라우터를 가상 게이트웨이 하나로 묶는 것 + 활성 라우터 장애 시 자동 장애 조치(d2-297)
- WPA2 PSK + 특정 클라이언트만 허용: `WPA2 Policy` 켜기 + `MAC Filtering` 켜기(d2-313)
- JSON 구조 읽기: 객체 { } 1개 안에 키 2개(apple, ripe), 각 키의 값은 배열 하나·불리언 하나로 키마다 값 1개씩. 배열 안 원소는 별도 키로 세지 않음(d2-430)
- VoIP VLAN 설정: 기존 데이터 VLAN 액세스 포트에 `switchport voice vlan 73`만 추가하면 전화는 음성 VLAN, 뒤의 PC는 기존 데이터 VLAN 사용(d2-431)
- REST API 메서드: PATCH=부분 수정, PUT=전체 교체, POST=생성(d2-433)
- PortFast 이유: 토폴로지 변경(TCN) 신호로부터 포트 보호 + 링크 업 즉시 forwarding 상태로 전환(STP 자체에서 빠지는 것은 아님)(d2-483)

**복습 퀴즈 5문제 중 1개만 정답(정적 경로 다음 홉)**
- 요약 경로(summarization)는 작은 네트워크들을 "더 크게" 묶는 것(더 작게 쪼개는 게 아님)
- VLAN 호핑 방어는 네이티브 VLAN과 분리 배정(MAC 주소 제한 아님)
- FHRP 핵심: 가상 게이트웨이 + 자동 장애 조치
- PortFast는 "시간" 문제: 30초 단계 없이 즉시 forwarding + TCN 미발생

**CCNA 서브넷팅(VLSM) 시작**: 한 블록에서 호스트 수가 다른 서브넷 여러 개를 만들 때 큰 것부터 먼저 자르고 작은 것을 그 뒤에 붙이는 방법 학습 중 (진행 중, 완료 아님)
