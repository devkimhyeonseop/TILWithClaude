# 2026-11-06 복습: df·fstab·systemctl

## 배운 것
- df(남은 용량), du(폴더 크기), fdisk(파티션 나누기)
- /etc/fstab은 마운트 목록을 표로 적어 둔 파일 (명령어 mount와 다름)
- systemctl enable 서비스명 = 부팅 때 자동 시작

## 틀린 것
- df를 fdisk로 답함 (fdisk는 파티션 분할 명령어)
- /etc/fstab을 /etc/mount로 답함 (3일 연속 틀림, 이름 속 tab=표로 외우기로 바꿈)

## 다시 볼 것
- fstab: 내일과 일주일 뒤에 한 번 더 확인
