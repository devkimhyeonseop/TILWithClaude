# 2026-11-04 복습: 리눅스·윈도우 서버 오답 재확인 + CCNA 덤프 · 오픽

## 배운 것
- `/root`는 관리자 홈, `df`는 남은 디스크 용량, `/etc/fstab`은 마운트 설정 파일
- 윈도우 서비스 도구는 **서비스**, 계정·그룹 도구는 **로컬 사용자 및 그룹**
- 공유 권한과 NTFS 권한이 다르면 **더 제한적인 쪽**이 적용된다

## 틀린 것
- 남은 디스크 용량 명령을 `/mount`로 답함 → `df` (disk free)
- 공유 권한 vs NTFS 권한 문제에 "공유 권한"이라고 답함 (3일째) → "더 제한적인 쪽"이 답
- 오늘 6문제 중 4개 정답 (어제 틀렸던 서비스, 로컬 사용자 및 그룹, `/root`, fstab은 맞힘)

## 다시 볼 것
